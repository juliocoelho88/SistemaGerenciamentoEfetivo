Importar efetivo
Cadastre o efetivo em massa a partir das planilhas de Excel

1Escolha as planilhas

Aceita .xlsx e .xls. Pode mandar várias de uma vez — por exemplo, uma por companhia.

Arraste as planilhas para cá ou clique para escolher no computador

    2Ajuste as opções

    Os padrões abaixo só são usados quando a planilha não traz a coluna correspondente.

    Se o RE já existir, os dados da planilha substituem os do sistema. Desmarcado, esses registros são apenas ignorados.

    3Confira antes de gravar

    Simule primeiro: a conferência mostra tudo que seria recusado sem gravar nada no sistema.
